How it works

1 · The door

Your file is read once

Every column is classified from its own rows. Personal data is set aside. You check the reading before the room opens.

2 · The room

Ask anything

The model writes a plan. The server checks every step against what the data holds, runs it, and checks the words against the figures before you see them.

3 · The receipt

Every claim is traceable

A figure cites its variable, its value and its base. A quote is matched character for character. A claim that cannot be matched is never shown.

What you can ask

  • Why did consideration fall in the north?
  • Who gave up before opening an account, and why?
  • Which complaints are growing, and for whom?
  • Does that hold in every segment?
  • What is the most interesting thing in here?

Crosstabs, trends, gradients, tests, regressions, forecasts, text themes and quotes. One question, one population, one dimension, optionally against another. Every table has a base and a test on each cell.

Two ways to run it

Desktop

Installed on your machine. The file never leaves it. Only the question and computed tables reach the model.

Cloud in preparation

Log in at app.talktask.si. Nothing to install. One space per company.

What it will not do

It will not invent a figure, a quote or a respondent. It will not answer a question the data cannot carry. It will not apply a weight, scale a column or mark a value as missing unless the rows allow it. These refusals are counted as correct answers, and they are tested that way.
